# 宜昌旅游助手

一款聚焦宜昌及三峡地区的微信小程序，提供本地地点浏览、地图区域筛选、AI 旅游问答和行程定制。

## 当前功能

- 浏览景区、餐馆、文化场馆和露营地点，并查看图文详情
- 在地图上选择宜昌不同区域，查看地点标记并进入详情
- 通过两个 Dify Chatflow 分别完成旅游问答和行程定制
- 查看收藏、浏览记录以及按会话保存的 AI 记录

当前版本为 **1.0.2**。地图采用手动选择区域，不读取用户当前位置。“本地苍蝇馆子”评价体系及配套后台属于后续规划，尚未包含在此版本中。

## 技术说明

项目使用原生微信小程序、TypeScript 和微信云开发。地点资料由云数据库提供；AI 请求通过云函数调用 Dify，不在小程序前端保存 API Key。

## 本地开发

需要 Node.js 22.12 或更新版本、微信开发者工具，以及自行配置的微信云开发环境。

```bash
npm install
npm run build
npm test
```

构建后，可使用微信开发者工具打开项目。云环境配置、数据库内容和 Dify 密钥不包含在本仓库中；没有这些配置时，在线功能不能直接使用。请勿将密钥提交到 GitHub。
