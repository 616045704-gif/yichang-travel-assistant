## 5. 体验版上传步骤

1. 在项目根目录执行 `npm run build` 后，微信开发者工具只导入 `dist` 并确认通过编译。该默认命令会生成调用云函数 `aiService` 的体验版包；`npm run build:dev` 只生成 `dist-dev` 的模拟包，不能导入或上传。
2. 点击右上角“上传”，版本号填 `0.1.0`，备注写“体验版首版”。
3. 上传成功后，登录 mp.weixin.qq.com →“版本管理”→“开发版本”→“设为体验版”。
4. 生成体验版二维码，交体验成员扫码验证。
