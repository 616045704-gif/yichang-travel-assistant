# 发现、首页与个人服务恢复设计

## 目标

恢复“全部”与搜索、首页云端精选地点、收藏/浏览/偏好个人服务，并将详情收藏按钮收紧为单行紧凑控件。

## 设计

- 地点客户端仅在分类非空时发送 `category`；云函数同时将空字符串兼容为未筛选，避免旧客户端再次造成“全部”失败。
- `placeService` 新增只读 `home` 动作，复用已发布地点的列表仓储，返回前四条有封面优先的地点作为 `featured`。首页在显示时请求它并以现有地点卡片呈现加载、空和错误状态。
- `userService` 保持已有可信微信身份和私有集合读写模型，只补充云 SDK 部署依赖后部署；不改变权限、数据库规则或任何用户数据。
- 详情页收藏按钮明确设置紧凑宽度、内边距与不换行，保留已有收藏行为。

## 验证

自动化覆盖空分类省略、服务端空分类兼容、首页精选结果、userService 部署包依赖和紧凑按钮样式；运行完整检查并由独立测试验收。部署后用开发者工具实际验证首页、全部搜索和一次收藏/浏览/偏好操作。
