# 分类 Tab、地图与“我的”页面视觉重构设计

## 目标与边界

本轮只重构发现页分类区、地图页分类/点位/地点弹卡和“我的”页视觉。保留现有五类筛选值、页面入口、跳转、定位授权时机、云函数、数据库字段、Dify、接口和用户数据逻辑。

参考图中的“停车场”不加入产品。分类仍为：全部、景区、餐馆、文化馆/博物馆、露营地。

## 视觉方向

### 色彩

- 导航与主要浮层：`#FFFFFF`
- 页面底色：`#F8F7FB`
- 轻紫选中底：`#F0ECFF`
- 选中描边：`#D9CEFF`
- 品牌紫：`#7454D8`
- 正文：`#29243A`
- 次级文字：`#756E82`
- 阴影：`rgba(53, 39, 92, .10)`，只用于悬浮分类栏、地图弹卡和“我的”顶部身份卡

不增加大面积高饱和紫色块。视觉记忆点集中在本地图标组成的分类栏与“我的”顶部旅行纹样。

### 字体层级

- 地图弹卡地点名：`34rpx / 750`
- “我的”主标题：`40rpx / 750`
- 功能入口标题：`28rpx / 700`
- 分类标签：`22–23rpx / 700`
- 说明文字：`22–24rpx / 400–500`

继续使用系统无衬线字体，不引入古风字体。

## 共享分类 Tab

发现页和地图页共用 `category-filter` 组件，组件从原生下拉 picker 改为横向滑动的图标 Tab，但继续接收 `value`，继续触发 `categorychange: { category }`。

```text
┌──────────────────────────────────────┐
│ [全部] [景区] [餐馆] [文化馆/博物馆] [露营地] → │
└──────────────────────────────────────┘
```

- 每项为圆角矩形，图标在上、文字在下。
- 全部五项使用 `assets/provided/category-*.png`，这些文件来自用户本地 `icon+banner`，不得重绘或改色。
- 普通态白底、深色文字；选中态为浅紫底、紫色文字和细紫边。
- 图标显示 `56rpx`，Tab 高度约 `112rpx`；长标签使用更宽的单项，不压缩字号。
- 容器横向滚动，无换行；切换后由组件发出原有分类值。

发现页中，Tab 位于现有头图下方，搜索框独占下一行。地图页中，Tab 是地图顶部的白色悬浮栏，左右各留 `20rpx` 安全距离。

- 空白、错误、加载与反馈提示继续使用现有组件。

## 地图页

### 分类栏与点位

- 顶部使用共享横向图标 Tab。
- 地图点位不再共用同一个紫色标记。生成 `map-marker-scenic/restaurant/culture/camping.png` 四种派生图。
- 每个点位仍是统一的紫色定位针轮廓，针内嵌对应的用户本地分类插画缩略图，因此轮廓统一、类别可辨。
- 点位尺寸约 `44 × 54px`；不改变 marker ID、坐标、筛选和点位到地点的映射。

### 选中地点弹卡

```text
┌──────────────────────────────────────┐
│ ┌────────图片────────┐  [分类图标] 分类 │
│ │                    │  地点名称         │
│ └────────────────────┘  [查看详情  ›]   │
└──────────────────────────────────────┘
```

- 使用白色底部浮卡、`30rpx` 圆角和一层轻阴影。
- 左侧为现有系统占位图，因为当前 `PlaceMarker` 接口不含图片字段；本轮不扩展接口或数据库字段。
- 右侧分类行使用对应本地图标，地点名最多两行，按钮为小面积紫色胶囊。
- 定位按钮位于弹卡上方居中；加载、拒绝和“打开设置”逻辑与文字保持不变。

## “我的”页面

### 顶部旅行身份区

```text
┌──────── 淡紫旅行纹样背景 ────────────┐
│ 我的旅行                              │
│ 留下你的出发线索         [淡化景区图标] │
│      · · · 路线纹样 · · ·            │
└──────────────────────────────────────┘
     ┌──── 白色旅行者身份卡 ────┐
     │ [我的图标] 你好，旅行者   │
     │           收藏灵感……     │
     └──────────────────────────┘
```

- 页面整体使用淡紫灰背景，而不是纯白。
- 顶部为很浅的紫白渐变；以用户提供的景区、露营地等图标做低透明度背景纹样，并用 CSS 点线路径连接，形成现代旅行地图感。
- 身份卡轻微压在顶部背景下缘，使用本地“我的”选中图标，不创建头像或登录入口。
- 保留现有“我的旅行 / 留下你的出发线索 / 你好，旅行者”文案。

### 功能入口区

- 收藏、浏览记录、AI 问答记录、旅行偏好四个入口仍使用现有本地图标、现有标题/说明和现有 URL。
- 入口放入一个白色圆角功能面板；每行图标使用不同的浅色图标底座，标题/说明左对齐，右侧紫色箭头。
- 增大图标到 `72rpx`，增加行间留白和按压反馈，但不新增入口。
- 隐私说明作为单独的次级白色面板；隐私提示和版本信息保留。

## 数据流与交互合同

1. `category-filter` 仍以 `CATEGORIES` 为唯一分类来源，并在点击时触发 `{ category: Category | '' }`。
2. Discover 和 Map 的 `onCategoryChange` 方法、搜索、列表请求与附近筛选保持不变。
3. 地图 marker 的 `id`、经纬度和查找逻辑保持不变，只按 `place.category` 选择不同 `iconPath`。
4. 地图弹卡仍由 `onMarkerTap` 设置 `selectedPlace`，仍由 `openSelectedPlace` 进入原详情页。
5. “我的”页面 `entries`、`openEntry`、`showPrivacy` 和 URL 全部不变。

## 状态与适配

- 分类栏在窄屏横向滚动，不能挤压、换行或遮挡地图触控。
- 地图弹卡需兼容两行地点名；无地点图片统一使用现有 `place-placeholder.jpg`。
- 定位加载、拒绝、设置按钮和错误提示不得被弹卡覆盖。
- “我的”背景图标只作装饰，使用 `aria-hidden`，不得阻挡菜单点击。
- 所有页面继续使用白色顶部导航和底部原生 Tab。

## 验收标准

1. 发现和地图均显示同一套五项横向图标 Tab，图标来自用户本地素材，切换结果一致。
2. Discover 搜索框在 Tab 下方全宽显示，原搜索与列表逻辑可用。
3. 四类地图点位图形不同，点击仍选择正确地点。
4. 地图弹卡具有图片、分类图标、地点名和详情按钮，长名称及定位提示不重叠。
5. “我的”顶部有淡色旅行图案、身份卡和更清晰的入口面板，不出现大面积高饱和紫色。
6. 我的收藏、浏览记录、AI 问答记录、旅行偏好和隐私说明仍进入原页面。
7. 云函数、Dify、数据库、共享接口、页面路由和定位授权逻辑无变化。
8. 相关单元测试、类型检查、Lint、开发构建、包体检查和独立视觉/测试验收通过；微信端无法现场验证时必须如实记录。

## 自检

- 无新增停车场、支付、购票、预约、登录或商家入口。
- 无 TBD/TODO。
- 本地分类图标只复用与缩放，不重绘或改色。
- 地图新增资源是本地分类插画的点位派生图，不引入外部素材。
