# 宜昌山水文旅视觉调整

## 用户依据

用户提供福州文旅页面作为整体风格参考，并明确要求地图分类独立悬浮、背景板透明。本次直接落实该视觉方向；功能范围仍以项目主设计为准。

## 视觉方案

采用宣纸米色、青绿山水、朱红印章与古金细线。相较仅换配色，原创山水主视觉更接近参考图；相较照搬原图，宜昌自己的标题、内容和四页结构更符合项目。首页使用生成的装饰山水长卷，正文保持清晰系统字体，标题优先宋体，缺失时回退 serif。

首页呈现宜昌标题、山水背景、四分类印章、旅行助手卷轴卡片及真实空状态。发现页、我的页采用相同纸色、标题、徽章与卡片。导航沿用四个原生 tab，选中朱红，保持可点击目标尺寸。参考图中的预约、订购等不加入项目。

地图铺满内容区域，分类容器无背景、无边框、无整块阴影，按钮之间透明且不阻挡地图拖动。每颗按钮保留独立浅米底与细边以保证底图上的可读性；选中用朱红强调。筛选与地标数据逻辑保持现有契约，不加入假地点。

## 资源与验收

装饰图为内置图像生成工具新作，不复制参考截图或福州建筑，不作为地点照片。生成提示、用途及保存位置记录于 UI 说明。现有图标用源码改色并重新导出。

验证主题资源可打包、四页布局、透明分类容器、按钮可点、原生标记筛选、隐私说明与状态分支。单元测试、类型、静态、构建、包检查、文档与模拟器全部通过后提交；真机字体差异与地图手势仍须真机验收。
