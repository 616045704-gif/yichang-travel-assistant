# 分类大地图调整

依据用户在四页预览后的明确反馈：“不需要下面的看看身边的宜昌，就是一张大地图，点击不同的分类，地图上显示不同的地标”。本说明补充[原产品设计](2026-09-04-yichang-travel-mini-program-design.md)，覆盖本次地图页布局。

## 已确认方向

地图占满导航栏和底部 tab 之间的内容区，默认宜昌城区，允许拖动和缩放。顶部悬浮全部、景区、餐馆、文化馆/博物馆、露营地按钮，沿用现有颜色与触达尺寸。移除页内标题、地图下方说明、附近卡片、定位按钮和大块空状态。

点击分类只更新对应地点标记；切回全部显示全部已提供的有效地点。切换分类保留当前地图视野。标记使用稳定数字 ID、原创标记图标，点击显示地点名称。没有地点时保持干净地图，不构造真实地标。

## 数据与范围

当前云环境已创建，但地点数据和 placeService 尚未接入。本次提供接收已发布云端地点结果的 setPlaces 方法与可测试的筛选/标记转换逻辑，初始地点数组为空。真实数据仍遵守原设计的云数据库来源要求，实际云服务连接沿用主计划任务 08–10，不把注入测试数据当云端已连通。

这次不读取用户位置，也不新增任何云资源。原设计的主动授权与不保存位置规则继续约束未来定位能力；当前地图页不再放附近卡片或定位入口。

## 验收

- 地图占满内容区，底部 tab 可用，分类悬浮且可点击。
- 景区、餐馆、人文和露营地分类仅保留匹配标记；全部恢复各类标记。
- 无效坐标、未知分类和重复 placeId 不产生额外地图标记。
- 分类切换不修改中心坐标；不调用定位、存储或外部 AI。
- 单元测试、类型/静态/构建/包检查与真实模拟器布局、分类事件验证通过。
